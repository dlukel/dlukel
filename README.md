## Recent work

### [MaCake](https://github.com/dlukel/MaCake)

Adaptive bandwidth shaping for macOS, written in Swift. It adapts the cake-autorate controller to macOS and adjusts dummynet pipes as network latency changes.

The project documents both the improvement and its cost. In one recorded Starlink comparison, added p90 delay fell from 55.5 ms to 16.0 ms while throughput fell from 278.52 to 177.51 Mbit/s. Those results describe that test, not every connection. MaCake ports the controller, not Linux's CAKE queue discipline.

[Read the measurements](https://github.com/dlukel/MaCake/blob/main/docs/MEASUREMENTS.md)
